# Доступність (WCAG 2.2, рівень AA)

Застосовується до всього, що бачить або з чим взаємодіє користувач: сторінки, компоненти, форми, лендинги, листи.

## Структура
- Один `h1` на сторінку, заголовки без пропусків рівнів (`h2` → `h3`, не `h2` → `h4`).
- Орієнтири: `header`, `nav`, `main`, `footer`. У сторінки є `<html lang="...">` і змістовний `<title>`.
- Списки — `ul`/`ol`, таблиці даних — `table` з `th` (і `scope`).

## Зображення й медіа
- Інформативні зображення: `alt` описує зміст («Графік зростання продажів на 30%»), не «image».
- Декоративні: `alt=""` (або CSS-фон).
- Іконки без тексту: `aria-label` на кнопці/посиланні або прихований текст; сама SVG — `aria-hidden="true"`.
- Відео: субтитри; без автозапуску зі звуком.

## Інтерактив
- Дія → `<button>`, перехід → `<a href>`. Не `div`/`span` з `onClick`.
- Усе працює з клавіатури (Tab, Enter, Space, Esc для модалок), порядок фокусу логічний.
- Видимий стан фокусу: не прибирати `outline` без заміни.
- Текст кнопок і посилань зрозумілий без контексту: «Завантажити прайс (PDF)», не «Тут» / «Детальніше» (або з `aria-label`).
- Розмір цілі для натискання — щонайменше 24×24 px (краще 44×44 на мобільних).
- Модальні вікна: фокус переходить у модалку, повертається після закриття, `Esc` закриває, `role="dialog"` + `aria-modal="true"` + підпис.

## Форми
- Кожне поле має видимий `<label>` (зв'язаний через `for`/`id`) — плейсхолдер не замінює підпис.
- Правильні `type` і `autocomplete` (`email`, `tel`, `name`, `postal-code`).
- Помилки: текстом поруч із полем (не лише червоним кольором), зв'язані через `aria-describedby`, поле з помилкою — `aria-invalid="true"`.
- Обов'язкові поля позначені текстом/символом із поясненням, а не лише кольором.

## Колір і текст
- Контраст тексту: ≥ 4.5:1 (великий текст ≥ 18.66px жирний / 24px — ≥ 3:1). Для кнопок, рамок полів, іконок — ≥ 3:1.
- Колір не єдиний спосіб передати інформацію (помилка = колір + іконка/текст).
- Текст масштабується до 200% без втрат; розміри шрифтів у `rem`, без фіксованих висот блоків із текстом.
- Анімації: поважати `prefers-reduced-motion`; нічого не блимає частіше 3 разів на секунду.

## ARIA
- Спершу нативний HTML; ARIA — лише коли без неї ніяк. Неправильна ARIA гірша за відсутню.
- Динамічні повідомлення (успіх відправки форми, помилка) — у `aria-live="polite"` області.

## Швидка самоперевірка
- Пройти змінене місце тільки клавіатурою.
- Якщо є eslint-plugin-jsx-a11y / vuejs-accessibility / axe у проєкті — запустити.
