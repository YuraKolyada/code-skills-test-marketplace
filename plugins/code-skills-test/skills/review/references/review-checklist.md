# Фінальний чекліст для змінених файлів

Пройди перед тим, як сказати людині «готово» і перед збереженням чи публікацією змін. Розробник цей код не перевірятиме — цей чекліст і є перевірка.

## Стиль
- [ ] Форматер і лінтер проєкту пройшли на змінених файлах
- [ ] Код виглядає як сусідній: ті самі патерни, назви, підхід до стилів і перекладів
- [ ] Немає зайвих змін (переформатування чужих рядків, рефакторинг «заодно»)
- [ ] Булеві — з `is`/`has`/`with`; змінні-значення не починаються з дієслова; назви відповідають тому, що код робить зараз
- [ ] `async`/`await` + `try`/`catch`, без ланцюжків `.then()`
- [ ] Семантичні теги; жодних `div`/`span` з `onClick`; немає бібліотеки там, де вистачає нативного API/CSS
- [ ] Незворотні чи неочевидні дії мають підтвердження з поясненням наслідків
- [ ] Нічого «на майбутнє»: без абстракцій, обгорток, опцій і конфігів, яких не просили; використано наявне в репозиторії, а не написано заново
- [ ] Виправлення бага — у спільному коді, а не в одному з викликів; усі виклики перевірено
- [ ] Перенесений чи об'єднаний код зберіг обробку помилок і валідацію
- [ ] Коментарі пояснюють лише «чому»
- [ ] Немає налагоджувального коду (`console.log`, `var_dump`, `print`) і закоментованих блоків

## Безпека
- [ ] У diff немає секретів, `.env`, ключів
- [ ] Немає неекранованого HTML з даних, склеєного SQL, вводу в shell-команди
- [ ] Вхідні дані на сервері валідуються; права доступу перевіряються
- [ ] Зміни в оплаті/авторизації/персональних даних окремо пояснені людині й підтверджені нею

## Доступність (якщо зміна видима користувачу)
- [ ] Зображення мають доречний `alt`, іконки-кнопки — `aria-label`
- [ ] Поля форм мають `label`, помилки — текстом
- [ ] Кнопки — `button`, посилання — `a`; працює з клавіатури, фокус видно
- [ ] Контраст достатній; колір не єдиний носій інформації

## Робота продукту
- [ ] Typecheck / тести / build (якщо є) пройшли
- [ ] Якщо проєкт можна запустити — зміна перевірена на вигляд (мобільна і десктопна ширина)
- [ ] Тексти для користувачів — у системі перекладів, у всіх мовах (якщо вона є)
